## 3. Dashboard, Navigation, & UI Audit

- **Dashboard (`HomeScreen.kt`, `HomeViewModel.kt`):**
  - `QuickScanSection` routes card #5 to `onNavigateToCallProtection` instead of `onNavigateToMessageScan`, ignoring the Message Shield callback.
  - `ProtectionActivitySection` uses `Brush.verticalGradient` (violates `DESIGN.md`).
  - `HomeViewModel` outputs `protectionScore = 100` even when `0` scans have been completed and derives activity metrics from `AlertEntity` + legacy video/message counters rather than unified scans across all 6 core modules and vault health.
  - Double bottom padding (`.padding(bottom = 88.dp)` combined with outer `Scaffold` padding).
- **Theme (`core/.../Theme.kt`, `Color.kt`):**
  - `dynamicColor = true` by default overrides `DESIGN.md` Sentinel Clinical Palette on Android 12+.
- **Bottom Navigation Bar & Hubs (`Navigation.kt`, `ScanHubScreen.kt`, `ToolsHubScreen.kt`):**
  - Bottom bar lacks a `1dp` top `#E6E9EF` divider, uses `Icons.Filled.CropFree` for `Scan`, shifts tab label weight (`Normal` -> `Bold`) on selection, and pairs with `ScanHubScreen` which renders an animated neon pulsing `Canvas`, rainbow-tinted tiles, unverified `"Models improve with each scan"` copy, and omits **Device Antivirus** and **Password Vault**.
  - `ToolsHubScreen` filter chips sit in a non-scrollable `Row`.
- **Database (`DeepfakeShieldDatabase.kt`, `DatabaseModule.kt`):**
  - Version `3` stores alerts, domain/phone reputation, audit logs, and incident `vault_entries`, with **no** unified `scan_history` table and **no** encrypted `vault_credentials` table.
